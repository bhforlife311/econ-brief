# 아침의 경제

매일 아침 8시에 자동 발행되는 한국 경제 브리핑입니다.

**읽기:** https://bhforlife311.github.io/econ-brief/

## 구성

| 섹션 | 내용 |
|---|---|
| 시장 | 직전 거래일 종가 — 코스피, 코스닥, 원/달러, 그날의 주요 지표 하나 |
| 오늘의 헤드라인 | 주요 경제 뉴스 3건 + 짧은 소식 몇 줄 |
| 경제 지식 한 조각 | 그날 헤드라인과 맞물리는 용어 하나를 3단락으로 해설 |
| 정부 지원사업 | 기업마당·정책브리핑에서 모은 공고를 마감 임박순으로 |

## 파일 구조

```
index.html              최신호
archive.html            지난 호 목록
archive/YYYY-MM-DD.html 날짜별 사본
```

발행 절차는 Claude Code 클라우드 루틴이 매일 자동으로 수행합니다. 루틴은 저장소를 클론해 자료를 수집하고, `index.html`을 갱신하고, 같은 내용을 `archive/`에 날짜별로 복사한 뒤 `archive.html` 목록 맨 위에 한 줄을 추가해 `main`에 푸시합니다.

## 디자인

원장(ledger) 느낌의 초록빛 종이 바탕. 제목은 Gowun Batang, 본문은 IBM Plex Sans KR, 숫자는 IBM Plex Mono. 지수 등락은 한국 관행대로 상승 빨강 / 하락 파랑입니다. 라이트·다크 테마 모두 지원합니다.

CSS는 `index.html` 안에 인라인으로 들어 있습니다. 매일 갱신되는 것은 본문 내용뿐이고 스타일과 마크업 구조는 고정입니다.

## 알림

기사 요약과 해설은 원문 보도를 바탕으로 재구성한 것이며, 각 호 하단에 출처 링크를 답니다. 투자 판단의 근거로 삼지 마세요.
